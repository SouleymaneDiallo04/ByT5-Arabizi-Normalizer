# Vue d'ensemble des données

Le corpus rassemble des paires **darija en écriture arabe ↔ darija en lettres
latines (arabizi)**, issues de quatre jeux de données publics de Hugging Face,
remises dans un format unique.

| Source | Lignes |
|---|---|
| `DrIAmed/darija-youtube-dataset` | 2 706 |
| `MBZUAI-Paris/DODa-10K` | 10 000 |
| `OiQ/daa-pairs` | 112 814 |
| `Haitam03/doda_synthetic` | 64 260 |
| **Total (avant nettoyage)** | **189 780** |

- {doc}`sources` : détail de chaque source et des colonnes utilisées
- {doc}`schema` : format des fichiers
- {doc}`reproduction` : comment reconstruire le corpus
- {doc}`limitations` : limites et précautions
